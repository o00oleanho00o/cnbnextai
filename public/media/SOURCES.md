# Image sources

The CNB product visuals are user-provided screenshots from the `reference/` folder. They are copied locally so the landing page does not depend on remote hotlinking at runtime.

- `cnb-dashboard.jpg`: CNB ERP home dashboard
- `cnb-sales-workflow.jpg`: CNB ERP sales workflow
- `cnb-roadmap.jpg`: CNB Engineering roadmap
- `cnb-estimate.jpg`: CNB project estimate / BOQ workspace

The older Unsplash files remain in this folder for local fallback use, but are no longer shown on the homepage.
